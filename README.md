# 农机外贸工作台（中文开源演示版）

一个独立、纯前端、默认离线的农机外贸工作台示例。项目使用 React、TypeScript 和 Vite，集中演示产品检索、双向属具匹配、人民币底价试算、汇率差额、贸易术语报价结构和税费公式拆分。

GitHub 项目：[shanheshile/nongji-waimao-workbench](https://github.com/shanheshile/nongji-waimao-workbench)。

> 本项目不是生产系统，也不是报价、报关或税务意见。仓库只含 6 条虚构 DEMO 产品和自制 SVG 占位素材，不含真实账号、客户、产品、供应链、价格、凭据或生产适配器。

## 功能

- 按中文名、英文名、型号、演示编码和 HS 候选检索产品；
- 拖拉机与农机具双向匹配，挖掘机与属具双向匹配；
- 清楚区分机器本体尺寸/重量与出口包装尺寸/重量/方数；
- 在“人民币底价 + 可选交易币种”旁手动填写利润加价率；
- 输入市场汇率和汇率差额后即时显示有效汇率与试算价格；
- 分开显示 EXW、FOB、CIF、DDP 的简化费用边界；
- 对任意具体目的国输入 HS 候选、关税率和 VAT/进口税率；
- 透明展示关税、VAT 计税基础和税费合计公式；
- 中文参数、英文原版参数与简洁预览三种显示方式；
- 全站无登录、无密码保存、无接口请求、无远程媒体。

## 快速开始

环境要求：Node.js 22 或更高版本、pnpm 11。

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

开发服务器默认只监听本机回环地址。构建与完整校验：

```bash
pnpm run ci
```

构建产物临时生成到 `dist/`；完整 CI 验证后会自动清理，且不会提交到仓库。需要部署时请单独运行 `pnpm run build`。

## 报价口径

此演示按下面的简化公式即时计算：

```text
有效汇率 = 市场汇率 - 汇率差额
利润参数价（CNY）= 人民币底价 × (1 + 成本加价率)
EXW = 利润参数价 ÷ 有效汇率
FOB = (利润参数价 + 国内出口费用) ÷ 有效汇率
CIF = FOB + 国际运费 + 保险费
关税 = CIF × 关税率
VAT 计税基础 = CIF + 关税 + 其他应税加项
VAT = VAT 计税基础 × VAT 税率
DDP 演示值 = CIF + 关税 + VAT + 其他进口侧费用
```

“成本加价率”和“对售价毛利率”不是同一指标，页面会同时显示。项目不会自动加载所谓实时汇率或国家税率，避免把旧数据或示例值误认为事实。

## 数据与安全边界

- 默认不登录，也没有账号输入框；
- 不保存密码、Cookie、令牌或浏览器身份；
- 不发起网络接口请求；
- 不包含任何生产域名、生产路径或部署配置；
- 不包含真实长编号、私有商业字段或大体量目录；
- 图片全部为仓库内自制 SVG；
- 税率初始为空并阻断税费/DDP；只有人工显式输入 0 才表示已核验的零税率。

详见 [数据边界](docs/数据边界.md)、[部署说明](docs/部署说明.md) 与 [安全接入指南](docs/安全接入指南.md)。

## 质量检查

`pnpm run verify:oss` 会检查：

- 未在公开白名单中的外部主机名与绝对路径；
- 疑似凭据、私有字段和真实长编号；
- 超大源文件、超量 DEMO 产品和远程媒体；
- 运行时网络请求与生产适配器痕迹；
- 直接及传递依赖的许可证是否位于允许集合。

任何检查、测试、类型检查或构建失败，CI 都会阻止合并。
