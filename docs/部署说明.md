# 部署说明

本项目是静态单页应用，不需要数据库或服务端会话。

## 构建

```bash
pnpm install --frozen-lockfile
pnpm run ci
pnpm run build
```

`pnpm run ci` 会在完成扫描、测试、类型检查和生产构建验证后清理临时 `dist/`；因此必须再单独运行 `pnpm run build` 生成待预览和发布的 `dist/`。本地预览：

```bash
pnpm run preview
```

## 静态托管

可以把 `dist/` 中的文件发布到任何支持 HTTPS 的静态托管服务。当前界面不使用前端路由，因此不要求特殊的回退规则。

建议设置：

- HTML 使用较短缓存，带哈希的 JS/CSS 使用长期不可变缓存；
- 响应头启用内容类型嗅探防护、严格来源策略和合理的内容安全策略；
- 只允许本项目自身资源，不开放不必要的脚本、框架或网络连接来源；
- 发布前先在全新目录解压并运行静态文件清单与敏感扫描。

## GitHub Pages

若使用项目子路径部署，需要在 `vite.config.ts` 中将 `base` 设置为仓库路径，然后重新运行完整 CI。不要直接手改 `dist/`。

## 回滚

每次发布应保存版本标签和对应构建哈希。发现问题时回滚到上一个已验证静态包，并在修复分支重新构建；不要覆盖式修改线上文件后继续使用旧版本号。
