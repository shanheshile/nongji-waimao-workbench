# 安全接入指南

开源版默认完全离线。若你要接入自己的业务系统，应把连接层作为独立、可替换的后端服务设计，不要把访问材料或私有数据写入本仓库。

## 推荐架构

```text
浏览器演示界面
  ↓ 仅向自己的同源后端发送最小请求
接入网关（鉴权、授权、限流、审计、字段裁剪）
  ↓ 服务端凭据，不下发浏览器
你有权使用的数据源
```

## 最小要求

1. 使用稳定且无业务含义的本地映射键，服务端再解析上游记录。
2. 产品、报价、订单、客户和素材分别授权，读取与写入权限分开。
3. 浏览器只接收当前页面需要的字段，避免把整库作为一次响应。
4. 所有写入使用防重键、预检、人工确认和独立回读。
5. 登录状态由服务端安全会话维护；前端不得保存密码或长期访问材料。
6. 错误响应固定返回 JSON，并设置正确状态码，不能把 HTML 错误页冒充数据。
7. 对汇率、税费、价格、包装和产品状态分别记录来源时间，不能互相代替。
8. 缓存必须包含过期时间、数据范围与账号范围，退出或切换身份后立即失效。

## 税费接入

官方查询候选与内部已核验证据应严格分层。只有产品、完整目的国税号、原产国、目的国和申报日期全部一致，且记录未过期、未撤销、来源可定位时，才允许自动预填。多个候选冲突、只有门户首页、非从价税或显式证据缺失时必须阻断正式计算。

## 素材接入

仅使用已确认许可和精确型号匹配的素材。素材回退顺序可以是稳定键、产品编码、规范型号；不要用模糊名称或搜索结果第一项自动绑定。对外展示前应再次检查图片、视频、资质的产品归属和授权范围。
