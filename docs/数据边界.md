# 数据边界

## 仓库内有什么

仓库只包含 6 条虚构产品记录。每条记录使用 `DEMO-` 前缀，价格、尺寸、重量、包装、HS 候选、参数和匹配关系均为界面演示所需的合成值。所有产品图片都是项目内自行绘制的 SVG。

## 仓库内没有什么

- 真实产品目录、客户记录、员工身份、订单、报价或利润；
- 真实供应链信息、工厂地址、联系方式或商业素材；
- 任何生产系统的域名、适配器、接口响应、访问材料或部署路径；
- 官方税率数据库、实时汇率服务或报关决定；
- 从其他私有项目复制的缓存、快照或构建产物。

## 离线发布快照

本项目把虚构演示数据编译进静态发布包，不提供网络快照刷新器。页面重新打开或刷新时读取当前部署版本内的数据；更新演示内容必须经过源码修改、测试和重新发布。目录观测时间、完整详情回读时间或生产同步状态均不在本项目能力范围内，不得用本地发布时间冒充上游详情回读时间。

## 字段语义

机器本体和出口包装是两套独立字段。页面分别显示本体外形尺寸、本体重量、包装尺寸、包装重量和包装方数，不能互相替代。

人民币底价只是虚构试算起点。利润输入是成本加价率；页面另算对售价毛利率。两者均不代表真实利润，因为演示数据不包含完整成本证据。

HS 只提供六位候选示例。目的国完整税号、原产地待遇、日期、关税、VAT、反倾销及其他措施必须从相应官方渠道重新核验。

## 属具匹配边界

`compatibleWith` 只是稳定演示 ID 关系，不能单独放行。匹配器还要求显式角色是“拖拉机 ↔ 拖拉机整体属具”或“挖掘机 ↔ 挖掘机整体属具”。未知角色、自走整机和备件一律不匹配，即使马力文字相同或数据误写了关系也不例外。三点悬挂、PTO 割草机等完整农机具应标记为 `tractor-implement`；离合器、刀轴皮带、驱动电机、发动机和履带等标记为 `spare-part`。

## 图片回退边界

每个候选图片都必须是已确认归属于同一演示产品的 `/assets/` 本地 SVG。界面按数据声明的顺序逐个加载；路径非法或所有候选失败时显示明确占位，不访问远程媒体，不用模糊名称、搜索第一项或其他产品素材补位。

## 提交前检查

`verify:oss` 会递归扫描仓库（依赖目录和构建目录除外），发现生产痕迹、疑似敏感值、远程媒体或大数据时直接失败。扫描不能替代人工审查；维护者仍需逐文件检查提交差异。
